# ELC 6012 NET Híbrido

![Não validado][stage] ![Supports aarch64][aarch64] ![Supports amd64][amd64]

Fica entre a central **Intelbras ELC 6012 NET** e a nuvem Intelbras: repassa o tráfego
para a nuvem e envia os comandos do Home Assistant numa sessão própria.

> **Não validado.** Nos testes, o app oficial da Intelbras não reconectou através
> deste App. Para uso normal, prefira o **ELC 6012 NET Local**.
